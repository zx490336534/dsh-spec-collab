# Spec Collab

- 用户要录入、澄清、共审或交付需求时，调用 `spec_workbench`。要绑定项目时传入用户指定的绝对路径或当前项目的 `pwd -P`；只查看时可省略路径。
- 把工具返回的本机工作台链接给用户。创建需求时在工作台选择项目，Codex 会针对该项目的当前目录运行审核。
- 用 `spec_list` 查找需求 ID 和阶段，用 `spec_read` 读取正文、完整 commit、审核问题、候选修改、决策与 Ready 条件。较长需求可以用 `include` 选择所需栏目。打开单条需求时可把工具返回的链接直接给用户。
- 依据正文和可核实的项目证据解释问题与取舍。资料不可用时标为待核对。候选修改、评论和审核结果都以工作台当前 Git 版本为准。
- 把接受候选修改、保存正文、产品确认、研发确认和生成 Ready 留给工作台中的人操作。读回结果后再报告 Ready，工作流程以交付 Markdown 结束。
